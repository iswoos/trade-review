# UI/내비게이션 문제 해결 + 다크모드 수동 제어

## 배경

`feature/chart-first-dashboard-redesign` 병합·배포 후 실제 사용 중 드러난 문제들을 해결한다:

1. 다크/라이트모드를 유저가 직접 제어할 방법이 없음 (OS 설정만 따름)
2. 백업(CSV 내보내기/가져오기) 기능이 불필요함
3. 차트 화면에서 홈으로 돌아갈 방법이 없어 새로고침해야 함
4. 체결 날짜에 시각(선택) 입력이 없고, 최근 매매순 정렬의 동률 처리 기준이 없음
5. 검색 결과 드롭다운을 선택 없이 닫을 방법이 없음
6. (5번과 같은 원인) 검색 결과를 선택해도 드롭다운이 안 닫혀서 화면 전환이 안 된 것처럼 보임

체결시점 환율 자동조회, 메모 이미지 첨부는 범위가 더 크고 독립적이라 별도 작업으로 미룬다(사용자 확인).

## 1. 다크모드/라이트모드 수동 제어

지금은 Tailwind의 `prefers-color-scheme` 미디어쿼리로만 다크모드가 걸려 있어 유저가 제어할 수 없다. 홈 화면 상단(백업 아이콘이 있던 자리)에 **시스템 → 라이트 → 다크 → 시스템** 순으로 순환하는 토글 버튼을 추가한다.

- 선택값은 `localStorage`에 저장해 새로고침 후에도 유지.
- Tailwind v4의 `dark:` variant를 `@custom-variant dark (&:where(.dark, .dark *));`로 클래스 기반으로 바꾸고, "시스템" 모드에서는 `window.matchMedia('(prefers-color-scheme: dark)')`를 구독해 `<html>`의 `dark` 클래스를 자동으로 붙였다 뗐다 한다. "라이트"/"다크"를 명시 선택하면 시스템 설정과 무관하게 그 값으로 클래스를 고정한다.
- 버튼은 기존 아이콘 버튼 스타일(홈 화면 상단, `rounded-xl` 사각 버튼)을 그대로 재사용하고, 현재 모드를 나타내는 간단한 기호(⚙/☀/☾)만 바꿔 보여준다.

## 2. 백업 기능 제거

`BackupControls` 컴포넌트, 테스트, `HomeScreen`에서의 사용을 전부 삭제한다. 위에서 비워진 아이콘 자리는 다크모드 토글이 대신 차지한다.

## 3. 히스토리 기반 내비게이션 (홈 버튼 + 브라우저 뒤로가기)

지금 앱은 URL/히스토리 개념이 전혀 없다(주소창이 항상 고정). 최소한의 History API 연동을 추가한다:

- 홈 → 차트로 처음 진입할 때(`screen === 'home'`일 때 종목 선택) `history.pushState({ screen: 'chart', ticker, name }, '')`로 기록을 하나 추가한다.
- 이미 차트 화면에 있는 상태에서 검색·좌우 화살표로 다른 종목으로 전환할 때는 `history.replaceState`로 현재 기록만 교체한다 — 종목 전환마다 뒤로가기 스택이 쌓이면 홈으로 나가기 위해 여러 번 눌러야 하는 문제가 생기기 때문.
- `popstate` 이벤트를 구독해 `event.state`에 따라 화면 상태를 복원한다.
- 차트 화면 상단에 "홈" 버튼을 추가하고, 클릭 시 `window.history.back()`을 호출한다 — 브라우저 뒤로가기 버튼과 완전히 동일한 경로를 타게 해서 상태가 꼬이지 않게 한다.
- 마운트 시 `history.replaceState({ screen: 'home' }, '')`로 기준점을 만들어 둔다.

## 4. 체결 시각(선택) 입력 + 정렬 동률 처리

- `AddTradeSheet`의 "체결 날짜" 옆에 `type="time"` 입력("체결 시각(선택)")을 추가한다. 비워두면 지금처럼 날짜만(자정 기준) 저장되고, 채우면 날짜+시각을 합쳐 저장한다.
- "시간 모름 / 예약매매"를 켜면 날짜·시각 입력값을 모두 **공란으로 지운다**(지금처럼 기존 값이 흐리게 남아있지 않고, 진짜로 비워짐). 다시 끄면 날짜는 오늘 날짜로 복귀하고 시각은 비워둔 채로 둔다.
- **정렬 동률 처리**: `Position`에 마지막 매매의 `recordedAt`(내부 저장 시각, 화면 비노출)을 추가로 노출한다. `positionNav`의 "최근 매매순" 정렬에서 `lastTradeAt`(체결 시각, 이제 분 단위까지 있을 수 있음)이 같으면 이 값으로 2차 정렬한다 — 항상 유일하고 단조 증가하는 값이라 순서가 확정적이다.

## 5. 검색 드롭다운 닫기 (X버튼 + 바깥 클릭 + 선택 시 자동 닫힘)

`TickerSearch`에 세 가지를 추가한다:
- 입력창에 검색어가 있을 때만 보이는 X(지우기) 버튼 — 누르면 검색어·결과 초기화.
- 컴포넌트 바깥 영역을 클릭하면 자동으로 닫힘(검색어·결과 초기화) — `document`에 바깥 클릭 감지 리스너 등록.
- 결과를 선택하면(`onSelectTicker` 호출과 함께) 검색어·결과를 즉시 초기화 — 지금까지 이게 안 돼서 선택해도 드롭다운이 그대로 남아있었고, 그래서 "이동이 안 되는 것처럼" 보였던 문제(6번)의 실제 원인이었다.
