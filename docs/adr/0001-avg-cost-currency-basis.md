# 평단은 원화가 아닌 종목 거래 통화 기준으로 계산한다

미국 주식처럼 해외 종목을 거래할 때, 매수 기록을 '주' 단위와 '금액(원)' 단위로 혼용해서 입력할 수 있어야 한다. 평단을 원화 기준으로 통일하면 '주' 단위 입력마다 매번 그 시점 환율을 곱해 누적해야 해서 계산이 더 복잡해지고, 환율 변동이 실제 매수 판단과 무관하게 손익 표시에 섞여 들어가는 부작용이 있다. 대신 평단은 항상 종목의 거래 통화 기준으로 유지하고, '금액' 입력은 체결 시점 환율로 즉시 주식 수로 환산해 저장한다(Trade에 `fx_rate_at_trade` 필드 추가). 원화 환산이 필요한 화면에서는 표시 시점에만 계산하고 저장하지 않는다.
