# 시세 조회는 Vercel 서버리스 함수를 통해 프록시한다

기획서 12절의 "서버 0대" 원칙은 문자 그대로는 지키기 어렵다. 시세 소스로 검토한 yfinance/FinanceDataReader는 Python 라이브러리로 브라우저에서 실행할 수 없고, 그 기반인 Yahoo Finance 엔드포인트는 CORS를 지원하지 않아 브라우저에서 직접 fetch할 수도 없다. 대안으로 CORS를 허용하는 무료 API(Alpha Vantage, Finnhub 등)를 클라이언트에서 직접 호출하는 방법도 있었지만, 이 경우 API 키가 정적 JS 번들에 그대로 노출된다. 대신 정적 호스팅과 같은 Vercel 프로젝트 안에 시세 조회 전용 서버리스 함수(`/api/price` 등)를 두고, 이 함수가 시세 소스를 호출해 결과만 클라이언트에 전달한다. "서버 0대" 원칙은 "상시 가동 서버 0대"로 재해석한다 — 서버리스 함수는 요청이 있을 때만 실행되고 상시 비용이 없으므로 원칙과 상충하지 않는다. 정적 호스팅 후보(Vercel/Netlify/Cloudflare Pages/GitHub Pages) 중에서도 Vercel로 좁힌 이유는, 같은 프로젝트 안에서 정적 사이트와 서버리스 함수를 하나의 배포로 관리할 수 있어 운영이 가장 단순하기 때문이다. 개인 프로젝트 규모의 트래픽에서는 Vercel Functions 무료(Hobby) 티어(월 100만 회 호출)로 비용은 계속 0원이다.
