# 이동평균선 상한을 1~2개(20·60일)에서 5개(5·20·50·100·200일)로 확대한다

기획서 3절 설계 원칙 3번은 "이동평균선 1~2개(20·60일)가 상한"이라고 못박았고, 8절 비목표는 "트레이딩뷰 수준의 차트·기술지표 재현"을 만들지 않는다고 명시했다. 이는 1인 개발로 트레이딩뷰의 차트 기능과 경쟁하지 않겠다는 포지셔닝(4절)에서 나온 의도적 제약이었다. 그러나 사용자가 실제 복기에는 5/20/50/100/200일 이동평균선이 필요하다고 판단해, 이 상한을 공식적으로 5개로 확대하기로 했다. 20일선과 200일선은 굵게 강조 표시한다(단기/장기 기준선으로서의 중요도가 높기 때문). 이 결정은 3절의 "차트는 복기에 필요한 만큼만" 원칙과 여전히 상충하는 지점이 있다는 걸 인지하고 내린 것이다 — RSI·MACD 같은 오실레이터/모멘텀 지표까지 늘리자는 요청은 아니며, 이동평균선(추세 확인용)에 한정된 확대다. 향후 다른 지표 추가 요청이 오면 이 ADR을 근거로 "이동평균선 확대는 이미 예외를 인정했지만, 그 외 지표는 여전히 8절 비목표"라는 선을 그어 재확인해야 한다.
