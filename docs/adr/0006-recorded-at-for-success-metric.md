# Trade에 recorded_at을 추가해 기록 지연을 내부적으로만 측정한다

ADR-0001~0005 이전에, 이 프로젝트의 MVP 성공 기준은 "체결 후 30분 이내에 이 앱에 기록한 비율"로 정했다(그릴링 Q1). 그런데 5절 데이터 모델의 `datetime`은 체결 시각일 뿐, "언제 이 앱에 저장됐는지"는 어디에도 남지 않아 이 지표 자체를 계산할 방법이 없었다. 이 필드는 처음부터 있어야 한다 — 나중에 추가하면 그 전에 입력된 기록들은 지표를 소급 계산할 수 없기 때문이다. 대신 Trade에 `recorded_at`(기기에 실제로 저장된 시각, 자동 기록·수정 불가)을 추가한다. 다만 이 값은 화면에 노출하지 않는다 — 설계 원칙 "거울이지 성적표가 아니다"에 따라, 사용자가 "얼마나 늦게 기록했는지"를 앱 안에서 직접 보게 만들면 안 되고, 개발자 본인이 성공 기준을 검증할 때만 내부적으로 쓰는 값이다.
