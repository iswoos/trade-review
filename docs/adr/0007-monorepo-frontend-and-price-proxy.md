# 프론트엔드와 시세 프록시 함수를 하나의 저장소로 통합한다

ADR-0003에서 시세 조회를 Vercel 서버리스 함수로 프록시하기로 하면서, 이 백엔드 코드를 프론트엔드와 같은 저장소에 둘지 분리할지 정해야 했다. 이 프로젝트의 "백엔드"는 DB나 인증 없이 `yahoo-finance2` 호출 결과만 돌려주는 API 라우트 하나뿐이라, 독립된 서비스로 분리할 만한 무게가 없다. 저장소를 분리하면 오히려 서로 다른 도메인 간 호출이 되어 ADR-0003에서 피하려 했던 CORS 문제가 프론트-백엔드 사이에 다시 생긴다. 대신 프론트 코드와 `/api` 폴더(서버리스 함수)를 같은 Vercel 프로젝트, 같은 저장소에 두어 하나의 배포로 관리한다. 이 저장소는 `docs/agents/domain.md`에 이미 single-context로 설정돼 있으므로, 저장소를 분리하면 그 결정과도 어긋난다. 여러 프론트가 하나의 백엔드를 공유하거나 팀이 나뉘어 개발하는 상황이 되면 이 결정을 재검토한다.
