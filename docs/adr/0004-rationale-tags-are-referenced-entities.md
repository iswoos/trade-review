# 근거 태그는 문자열이 아니라 참조 가능한 개체로 관리하고, 삭제는 보관 처리한다

5절 데이터 모델은 근거 태그(매크로/팩트/차트/감/지인추천)를 "사용자 편집 가능"이라고만 명시했고, 편집이 과거 Trade 기록에 미치는 영향은 정하지 않았다. 태그를 Trade에 문자열로 그대로 저장하면, 이름을 바꿀 때 과거 기록을 일일이 갱신해야 하고 삭제하면 과거 기록의 근거가 통째로 사라진다. 대신 태그를 ID를 가진 별도 목록으로 관리하고 Trade는 그 ID를 참조한다. 이름 변경은 같은 개념의 표시 이름만 바뀌는 것이므로 과거 기록에도 즉시 반영된다. 삭제는 완전 삭제가 아니라 보관(비활성화) 처리한다 — 신규 입력 시 선택 목록에서는 빠지지만 과거 Trade의 참조와 표시는 유지된다. 이는 후속 기능인 태그 분포·성향 리포트(S4)가 과거 데이터를 계속 활용할 수 있어야 하기 때문이다.
