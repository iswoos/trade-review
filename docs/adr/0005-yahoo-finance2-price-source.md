# 시세 소스는 yahoo-finance2(Node)로 미국·한국 주식을 함께 커버한다

사용자는 미국·한국 주식을 함께 거래하므로, 시세 소스 하나로 두 시장을 모두 커버할 수 있어야 한다. 원래 기획서(6절)가 제안한 `yfinance`는 Python 라이브러리라 Vercel 서버리스 함수의 Node 런타임에서 그대로 쓸 수 없다. 대안으로 검토한 Finnhub/FMP는 한국 종목(KRX) 무료 티어 지원 여부가 공식 문서상 확인되지 않아 리스크가 있다. 대신 Yahoo Finance 데이터를 Node에서 쓸 수 있게 만든 비공식 패키지 `yahoo-finance2`를 서버리스 함수 안에서 호출한다 — 서버 대 서버 호출이라 브라우저 CORS 문제와 무관하고, 한국 종목도 `005930.KS` 같은 `.KS` 접미사로 동일한 인터페이스로 조회된다. 비공식 API라 Yahoo가 구조를 바꾸면 깨질 수 있다는 리스크가 있으나, 6절에 이미 명시된 "시세 조회 실패 시 수동 입력 폴백"으로 대응한다.
